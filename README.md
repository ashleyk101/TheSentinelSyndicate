# The Sentinel Syndicate – website

Premium marketing website for The Sentinel Syndicate, a Kenyan racehorse syndicate. It is a fast static site generated by a small Node script with no dependencies.

## Quick start

```bash
node scripts/build.js        # builds the site into dist/
node scripts/serve.js        # preview at http://localhost:4173
```

You need Node 18 or later. Upload the contents of `dist/` to any static host, for example Netlify, Cloudflare Pages, Vercel or cPanel hosting. On Netlify or Cloudflare Pages, set the build command to `node scripts/build.js` and the output folder to `dist`.

## Updating content (no design work needed)

All content lives in `src/content/`. Edit the JSON and rebuild.

| File | What it controls |
| --- | --- |
| `site.json` | Contact details, WhatsApp, social links, form key, analytics, budget ranges, team, milestones |
| `horses.json` | Every horse: name, photo, age, sex, pedigree, status, record, recent runs, updates, share price |
| `tiers.json` | Ownership shares (Entry/Growth/Strategic), club memberships (Silver/Gold/Diamond), the 55/45 structure |
| `images.json` | Photo library. Use Unsplash IDs, Wikimedia Commons paths, or your own files in `src/assets/img/` |

- **Add a horse:** copy an entry in `horses.json`, give it a unique `slug` (this becomes `/horses/<slug>/`), and set `"sample": false`. Leave unverified fields as `null` and the site shows "To be confirmed" or hides them. Racing records only show as figures when `"verified": true`.
- **Status values:** `available`, `racing`, `in-training`, `fully-subscribed`, `retired`, `sold`. Horses that are not available automatically offer a "Register interest" enquiry.
- **Filters** on the horse directory only appear when there is more than one value to filter by.
- **KES pricing:** set `priceKES` on a tier (or `fromKES` on a horse) and it is shown alongside or instead of USD.
- **Team and news:** add entries to `team` and `milestones` in `site.json` to replace the "to be added" notes on Our Syndicate.

## Before launch – checklist

1. **Remove the sample horses.** Set `"showSampleHorses": false` in `site.json` and add real horses. With no horses, the site shows an enquiry panel instead of listings.
2. **Connect the enquiry forms.** Create a free access key at [web3forms.com](https://web3forms.com) using `partner@sentinelsyndicate.com` and paste it into `forms.accessKey` in `site.json`. Until then, forms validate but tell visitors that online enquiries are being connected and show phone, WhatsApp and email. They never report a false success.
3. **Legal review.** `/privacy/` and `/terms/` are drafts marked "Draft for legal review". Have a Kenyan advocate review them, including against the Data Protection Act, 2019, and fill in the [bracketed] items. Remove the draft notes in `src/pages/legal.js` afterwards.
4. **Compliance review** of all statements about ownership, shares, the stated USD 100,000 valuation and returns (see brief section 11).
5. **Photography.** Current images are illustrative. Kenyan scenes come from Wikimedia Commons and are credited on `/credits/`; the racing action shots come from Unsplash. Openly licensed photos of Kenyan races, such as Ngong Racecourse, are not available, so commission or license real race-day photography and add it via `images.json`.
6. **Analytics (optional).** Add a GA4 ID to `analytics.ga4MeasurementId`. A consent banner then appears, and analytics load only after a visitor accepts.
7. **Social links:** add confirmed accounts to `social` in `site.json`.
8. **Domain:** `url` in `site.json` (`https://www.sentinelsyndicate.com`) drives canonical URLs, the sitemap and Open Graph tags.

## What is built

- Pages: Home, Our Syndicate, Our Horses (searchable directory), one profile page per horse, How Ownership Works, Membership & Enquiries, Contact, Privacy, Terms, Photo credits, and a branded 404.
- Enquiry forms with accessible validation, a Kenyan and international phone check, horse- and tier-specific prefill (`/membership/?tier=growth`), a honeypot spam trap, and real submission via Web3Forms.
- SEO: titles, meta descriptions, canonical URLs, Open Graph tags, `sitemap.xml`, `robots.txt`, and JSON-LD (Organization, FAQ, Breadcrumb). Sample horse pages are `noindex` and left out of the sitemap.
- Accessibility: semantic headings, skip link, visible focus, keyboard-operable mobile menu, labelled form fields with linked error messages, and respect for reduced-motion settings.
- Performance: responsive `srcset` images, lazy loading below the fold, one small CSS file and one small JS file, and no frameworks.
- No payments, checkout, member portal or betting features, by design.
